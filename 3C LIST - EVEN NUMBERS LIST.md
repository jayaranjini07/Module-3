## REVERSE THE LIST

---

### AIM  
To write a non parameterized function to print the reverse of list that is entered by the user.

---

### ALGORITHM

1. Start
2. Prompt the user to input a list and evaluate it using eval() to convert the string input into an actual list.
3. Store the list in variable l.
4. Use the reverse() method on the list l to reverse the elements in place.
5. Print the reversed list.
6. End
---

### PROGRAM

```pyhton
def reverselist():
    l=eval(input())
    l.reverse()
    print(l)
```
